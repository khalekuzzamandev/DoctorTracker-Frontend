## 🌟 Project Overview

**Doctor Tracker** is a modern healthcare management application designed to help authenticated users efficiently manage doctors and their corresponding patients.

The platform provides a clean, professional, and responsive dashboard with essential CRUD operations for managing healthcare information.

The application focuses on two main management modules:

- **Doctor Management**
- **Patient Management**

Users can add, view, update, and delete doctor and patient records through an intuitive interface.

---

## ✨ Key Features

- 🔐 Secure User Authentication
- 👨‍⚕️ Add and Manage Doctors
- 🧑‍🤝‍🧑 Add and Manage Patients
- 📋 View All Doctors and Patients
- 🔍 View Individual Doctor and Patient Details
- ✏️ Update Existing Records
- 🗑️ Delete Doctor and Patient Records
- 📱 Fully Responsive Dashboard
- 🎨 Modern Healthcare Dashboard UI
- 🔗 RESTful API Integration

## ⚙️ Installation & Setup

Follow these steps to run the frontend project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/khalekuzzamandev/DoctorTracker-Frontend.git
```

### 2. Navigate to the Project Directory

```bash
cd DoctorTracker-Frontend
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env.local` file in the root directory:

```env
NEXT_PUBLIC_BASE_URL=https://doctor-tracker-backend-kappa.vercel.app
```

### 5. Start the Development Server

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```

## 🔌 Backend API Endpoints

| HTTP Method | Endpoint | Description |
|---|---|---|
| POST | `/api/adddoctor` | Add a new doctor |
| GET | `/api/get/doctor` | Get all doctors |
| GET | `/api/get/doctor/:id` | Get doctor by ID |
| PUT | `/api/update/doctor/:id` | Update doctor information |
| DELETE | `/api/delete/doctor/:id` | Delete a doctor |
| POST | `/api/addpatient` | Add a new patient |
| GET | `/api/get/patient` | Get all patients |
| GET | `/api/get/patient/:id` | Get patient by ID |
| PUT | `/api/update/patient/:id` | Update patient information |
| DELETE | `/api/delete/patient/:id` | Delete a patient |
